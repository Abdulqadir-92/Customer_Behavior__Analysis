# Customer_Behavior__Analysis
Customer Shopping Behavior Analysis using Python, PostgreSQL and Power BI. Analyzing 3,900 customer transactions to uncover shopping patterns, customer segmentation, revenue trends, product preferences and subscription insights through SQL queries and interactive dashboards.
# 🛍️ Customer Shopping Behavior Analysis
###  Data Analytics Project | Python • SQL • Power BI

## 📌 1. Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, sales performance, and revenue trends.

The project follows a complete end-to-end data analytics workflow, starting from dataset loading and data cleaning in Python to SQL-based business analysis and interactive dashboard development in Power BI.

The main objective is to transform raw customer data into meaningful business insights that help organizations make data-driven decisions.

## 📂 2. Dataset

The project uses a Customer Shopping Behavior dataset containing:

- **Total Records:** 3,900
- **Total Columns:** 18
- **Data Type:** Customer shopping and transaction data

### Key Features
- Customer ID, Age and Gender
- Product Category and Item Purchased
- Purchase Amount
- Subscription Status
- Discount Applied
- Shipping Type
- Review Rating
- Previous Purchases
- Purchase Frequency

## 🔄 4. Project Workflow

### Step 1: Data Loading
- Imported the dataset into Python using Pandas.
- Examined dataset structure, rows, columns and data types.
- Performed initial data exploration.

### Step 2: Exploratory Data Analysis (EDA)
- Analyzed customer demographics.
- Explored product categories and purchasing trends.
- Examined spending patterns.
- Identified missing values and data inconsistencies.

### Step 3: Data Cleaning
- Handled missing values in the Review Rating column.
- Standardized column names.
- Checked duplicate records.
- Created age groups.
- Performed feature engineering.
- Prepared the cleaned dataset for SQL analysis.

### Step 4: SQL Analysis
Loaded the cleaned dataset into a relational database and performed business analysis using SQL queries.

**Key Business Questions:**
1. What is the total revenue generated by male and female customers?
2. Who are the high-spending customers using discounts?
3. Which are the top 5 products by average rating?
4. How do Standard and Express shipping compare?
5. Do subscribers spend more than non-subscribers?
6. Which products depend most on discounts?
7. How can customers be segmented into New, Returning and Loyal?
8. What are the top 3 products in each category?
9. Are repeat buyers more likely to subscribe?
10. Which age group contributes the highest revenue?

### Step 5: Power BI Dashboard

- Created interactive charts and visualizations.
- Designed KPI cards.
- Added slicers and filters.
- Presented customer and revenue insights.
